# ASANYA PBL Inbox

This directory holds observations, ideas, possible future PBIs, and unresolved items that are worth retaining but have not been approved as numbered PBIs.

- Do not assign an ID merely because an inbox item exists.
- Promote an item only after explicit user agreement.
- When promoting an item, preserve relevant history and remove or clearly close the active inbox duplicate.
- Use [`../templates/inbox-item.md`](../templates/inbox-item.md) as the starting structure.

There are currently no genuine unnumbered items supported by the reviewed migration evidence. PBL-043 through PBL-045 were explicitly approved as numbered PBIs and therefore belong under `pbl/items/`, not here.
