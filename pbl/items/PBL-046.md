# PBL-046 — 7日後以降の期限表示に曜日を追加

- Type: UX / Visual
- Status: Validated RC
- Priority: Unspecified
- Released: —
- Schema impact: No
- Last verified: 2026-10-07

## Objective

1週間以上先の期限を日付だけでなく曜日と一緒に表示し、予定をカレンダーで確認しなくても曜日を把握できるようにする。

## Confirmed scope

- 今日から7日後以降で同一年の期限表示は `10/7 水` の形式にする。
- 今日から7日後以降で年が異なる期限表示は `2027/1/1 金` の形式にする。
- 曜日は日本語の1文字表記（`日`、`月`、`火`、`水`、`木`、`金`、`土`）とする。
- `昨日`、`今日`、`明日` の相対表示は変更しない。
- 2～6日後の `水曜日` などの曜日表示は変更しない。
- 期限の保存値、入力・編集動作、並び順、期限判定、Schema、persistenceは変更しない。
- ToDo／Projectで既存の共通期限ラベルを使う表示へ同じ形式を適用する。
- ToDo／Projectの期限列の既定幅を、`2027/12/22 水` が現在のフォントサイズのまま1行で収まる幅へ広げる。
- 旧既定幅は新しい既定幅へ移行し、ユーザーが手動設定した別の列幅は保持する。
- Ganttタイムラインの日付ヘッダーは今回の対象外とする。

## Acceptance criteria

- 7日後以降かつ同一年の期限が `M/D 曜` で表示される。
- 7日後以降かつ別年の期限が `YYYY/M/D 曜` で表示される。
- 曜日は対象日付から正しく算出される。
- `昨日`、`今日`、`明日`、2～6日後の既存表示が維持される。
- ToDoとProjectの該当期限表示が同じ共通ルールになる。
- ToDoとProjectの双方で `2027/12/22 水` が1行で表示される。
- 期限の永続化値は従来どおり `YYYY-MM-DD` のままである。
- 期限編集、日付ショートカット、sort、overdue、Undo／Redo、Search、Ganttの既存動作を壊さない。
- Product Versionの扱いはrelease boundaryで決定し、Schema Versionは変更しない。

## Open questions

- 2日前以前の過去日付にも曜日を追加するかは未合意。現時点の合意範囲には含めない。

## Relationships

- 共通期限ラベルと期限表示を利用する既存ToDo／Project UIに関係する。
- Ganttタイムラインの日付ヘッダー表示とは分離する。
